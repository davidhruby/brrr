# Rust

*General notes about Rust that I collect along the way, mostly for myself.*

## History

[How Rust went from a side project to the world's most-loved programming language](https://www.technologyreview.com/2023/02/14/1067869/rust-worlds-fastest-growing-programming-language/)
(Clive Thompson, MIT Technology Review, 2023): how Graydon Hoare's personal project, started
after a broken elevator in his building, grew with Mozilla's backing and many volunteers into
a language used by big companies for fast and reliable software.
